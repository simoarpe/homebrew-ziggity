# homebrew-ziggity

A [Homebrew](https://brew.sh) tap for [Ziggity](https://github.com/simoarpe/ziggity) — a terminal UI for Git, written in Zig.

## Install

```sh
brew install simoarpe/ziggity/ziggity
```

That's shorthand for tapping this repo and installing the formula:

```sh
brew tap simoarpe/ziggity
brew install ziggity
```

## Update

```sh
brew update
brew upgrade ziggity
```

## Uninstall

```sh
brew uninstall ziggity
brew untap simoarpe/ziggity
```

Formulae live in [`Formula/`](Formula). Each release points at the prebuilt
binaries published on the [Ziggity releases page](https://github.com/simoarpe/ziggity/releases).
